# VoiceMate (ボイスメイト)

ワンタッチで音声メモを録音し、自動的にテキストに変換してくれる、あなたの音声入力の相棒です。iPhoneのサイドボタンを使って素早く音声メモを録音し、OpenAI Whisperによる高精度な文字起こしを行い、自動的にメモアプリに保存します。

## 機能

- iPhoneのサイドボタン長押しで即座に録音開始
- 録音した音声ファイルをiCloud経由で自動同期
- OpenAI Whisperによる高精度な文字起こし
- 文字起こしされたテキストを自動でメモアプリに保存

## セットアップ手順

### 1. Mac側の準備

1. Python 3.7以上をインストールしていない場合は、[公式サイト](https://www.python.org/downloads/)からインストールしてください。

2. OpenAI APIキーを取得していない場合は、[OpenAIのウェブサイト](https://platform.openai.com/)で取得してください。

3. `.env`ファイルを作成し、APIキーを設定：
   ```
   OPENAI_API_KEY=your_api_key_here
   ```

4. セットアップスクリプトを実行：
   ```bash
   chmod +x setup.sh
   ./setup.sh
   ```

### 2. iPhone側の設定

1. ボイスメモアプリの設定：
   - 「設定」アプリを開く
   - 「ボイスメモ」をタップ
   - 「iCloudでの同期」をオンにする

2. サイドボタンの設定：
   - 「設定」アプリを開く
   - 「アクセシビリティ」→「サイドボタン」を選択
   - 「長押し」の項目を選択
   - 「ボイスメモ」を選択

### 3. iCloud同期の確認

1. Macで「システム環境設定」→「Apple ID」を開く
2. 「iCloud」を選択
3. 「ボイスメモ」が有効になっていることを確認

## 使い方

1. Mac側でスクリプトを起動：
   ```bash
   source venv/bin/activate
   python main.py
   ```

2. iPhoneで録音：
   - サイドボタンを長押しすると録音開始
   - 録音中は赤いインジケータが表示されます
   - もう一度サイドボタンを押すと録音終了

3. 自動処理の流れ：
   - 録音した音声がiCloudを通じてMacに同期されます（通常1-2分以内）
   - スクリプトが自動的に音声を検出し、Whisperで文字起こしを行います
   - 文字起こされたテキストは自動的にメモアプリに新規メモとして保存されます

## トラブルシューティング

### 音声が同期されない場合
- iCloudの同期が有効になっているか確認してください
- インターネット接続を確認してください
- iCloudストレージの空き容量を確認してください

### 文字起こしが開始されない場合
- スクリプトが実行中であることを確認してください
- OpenAI APIキーが正しく設定されているか確認してください
- 音声ファイルが正しく同期されているか確認してください

### メモアプリに同期されない場合
- Macのメモアプリが起動していることを確認してください
- iCloudアカウントにログインしていることを確認してください

## 注意事項

- OpenAI APIの使用には料金が発生します（約1分の音声で0.006ドル程度）
- 長い音声ファイルの場合、文字起こしに時間がかかることがあります
- iCloudの同期速度は通信環境に依存します
- バッテリー消費を抑えるため、使用しないときはスクリプトを終了することをお勧めします
